## 重要聲明

> 此版本為 **Pre-release** 測試版本，不是正式上線版本。
>
> - 使用 Android Debug 金鑰簽署，不適合公開發行或上架。
> - 功能與資料格式可能隨時調整。
> - 若後續變更簽署金鑰，可能需要先解除安裝才能更新。
> - 建議僅在測試裝置或可接受資料重置的環境安裝。

## 本次重新建置（同版號）

此版維持 `versionCode = 1`、`versionName = 1.0.0-prerelease`，重新建置並覆蓋同版號 Release。主要差異：

- 閱讀工具列新增全書進度百分比。
- 左右滑動換章改為約 20% 螢幕寬或快速輕甩觸發。
- 書本詳細資訊、EPUB 匯入與 HTML／CSS 快取效能調整。
- EPUB 檔案大小上限與 Room 降級保護等穩定性調整。

## 建置設定

`app/build.gradle.kts`：

```kotlin
defaultConfig {
    versionCode = 1
    versionName = "1.0.0"
}

buildTypes {
    create("prerelease") {
        initWith(getByName("release"))
        isMinifyEnabled = true
        isShrinkResources = true
        isDebuggable = false
        signingConfig = signingConfigs.getByName("debug")
        versionNameSuffix = "-prerelease"
        matchingFallbacks += listOf("release")
    }
}
```

建置指令：

```powershell
.\gradlew.bat :app:assemblePrerelease
```

輸出：

```text
app/build/outputs/apk/prerelease/app-prerelease.apk
```

## 版本命名規則

- 正式版本：`主版本.次版本.修訂版本`，例如 `1.0.0`。
- 測試版本：`主版本.次版本.修訂版本-prerelease`，例如 `1.0.0-prerelease`。
- Git tag 建議加上 `v` 前綴，例如 `v1.0.0-prerelease`。

## 安裝步驟

1. 下載 `app-prerelease.apk`。
2. 在 Android 設定中允許安裝未知來源應用程式。
3. 點擊 APK 安裝。
4. 若出現簽章衝突，先解除安裝舊版。

## 已知限制

- 不支援 DRM 保護的 EPUB。
- 不支援 PDF、MOBI、AZW3。
- 沒有雲端同步與跨裝置進度。
- 匯入的書籍與閱讀資料只存在本機。
- 解除安裝 App 會刪除書庫與閱讀紀錄。
- Room 資料庫僅在降級時使用破壞性遷移；未來升級 schema 仍需提供 Migration。
