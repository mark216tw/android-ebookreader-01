## 重要聲明

> 此版本為 **Pre-release** 測試版本，不是正式上線版本。
>
> - 使用 Android Debug 金鑰簽署，不適合公開發行或上架。
> - 功能與資料格式可能隨時調整。
> - 若後續變更簽署金鑰，可能需要先解除安裝才能更新。
> - 建議僅在測試裝置或可接受資料重置的環境安裝。

## 本次更新

`1.0.1-prerelease` 主要差異：

- 新增朗讀功能，支援背景播放、通知控制、暫停／續播、語速調整與依朗讀句自動捲動。
- 書架新增封面網格與緊湊清單切換。
- 閱讀器目錄與排版設定收納至頂部「更多」選單。
- 修正標籤改名後書籍標籤關聯消失的問題。
- 修正最近閱讀時間顯示「0 分鐘前」，改為「剛剛」。
- 修正朗讀未從目前位置開始、暫停後重播與自動捲動失效的問題。

## 建置設定

`app/build.gradle.kts`：

```kotlin
defaultConfig {
    versionCode = 2
    versionName = "1.0.1"
}

buildTypes {
    create("prerelease") {
        initWith(getByName("release"))
        isMinifyEnabled = true
        isShrinkResources = true
        isDebuggable = false
        signingConfig = signingConfigs.getByName("debug")
        versionNameSuffix = "-prerelease"
        matchingFallbacks += listOf("release")
    }
}
```

建置指令：

```powershell
.\gradlew.bat :app:assemblePrerelease
```

輸出：

```text
app/build/outputs/apk/prerelease/app-prerelease.apk
```

## 版本命名規則

- 正式版本：`主版本.次版本.修訂版本`，例如 `1.0.0`。
- 測試版本：`主版本.次版本.修訂版本-prerelease`，例如 `1.0.1-prerelease`。
- Git tag 建議加上 `v` 前綴，例如 `v1.0.1-prerelease`。

## 安裝步驟

1. 下載 `app-prerelease.apk`。
2. 在 Android 設定中允許安裝未知來源應用程式。
3. 點擊 APK 安裝。
4. 若出現簽章衝突，先解除安裝舊版。

## 已知限制

- 不支援 DRM 保護的 EPUB。
- 不支援 PDF、MOBI、AZW3。
- 沒有雲端同步與跨裝置進度。
- 匯入的書籍與閱讀資料只存在本機。
- 解除安裝 App 會刪除書庫與閱讀紀錄。
- 朗讀功能需要裝置具備可用的 TTS 引擎與書籍語言的語音資料。
- 朗讀範圍為目前章節，讀完後停止，不會自動接續下一章。
- 朗讀自動捲動以字元比例估算，實際位置可能與版面略有差異。
- Room 資料庫僅在降級時使用破壞性遷移；未來升級 schema 仍需提供 Migration。
