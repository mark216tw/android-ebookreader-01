# 開發與建置指南

本文件說明如何準備開發環境、建置、測試與發行 mini閱讀器。

## 1. 開發環境

| 工具 | 建議版本 |
| --- | --- |
| JDK | 17 |
| Android Studio | 支援 AGP 8.9.2 的版本 |
| Android SDK | Platform 35 |
| Gradle | 使用專案內 `gradlew` |
| Git | 任意近期版本 |

專案使用 Gradle Wrapper，不需要另外安裝 Gradle。

## 2. 取得專案

```bash
git clone https://github.com/mark216tw/android-ebookreader-01.git
cd android-ebookreader-01
```

## 3. 設定 SDK 路徑

確認根目錄的 `local.properties` 包含 Android SDK 路徑，例如：

```properties
sdk.dir=C\:\\Users\\YOUR_NAME\\AppData\\Local\\Android\\Sdk
```

`local.properties` 不應提交到版本控制。

## 4. 常用指令

Windows PowerShell：

```powershell
# Debug APK
.\gradlew.bat :app:assembleDebug

# 安裝到已連線裝置
.\gradlew.bat :app:installDebug

# 單元測試
.\gradlew.bat :app:testDebugUnitTest

# Lint
.\gradlew.bat :app:lintDebug

# Pre-release APK（R8 + Debug 簽署）
.\gradlew.bat :app:assemblePrerelease
```

macOS / Linux：

```bash
./gradlew :app:assembleDebug
./gradlew :app:installDebug
./gradlew :app:testDebugUnitTest
./gradlew :app:lintDebug
./gradlew :app:assemblePrerelease
```

## 5. 建置輸出

| Build Type | 輸出路徑 | 說明 |
| --- | --- | --- |
| `debug` | `app/build/outputs/apk/debug/app-debug.apk` | 開發用 |
| `prerelease` | `app/build/outputs/apk/prerelease/app-prerelease.apk` | 測試發行 |
| `release` | `app/build/outputs/apk/release/app-release-unsigned.apk` | 尚未設定正式簽署 |

## 6. Pre-release 建置設定

`app/build.gradle.kts` 中的 `prerelease`：

```kotlin
create("prerelease") {
    initWith(getByName("release"))
    isMinifyEnabled = true
    isShrinkResources = true
    isDebuggable = false
    signingConfig = signingConfigs.getByName("debug")
    versionNameSuffix = "-prerelease"
    matchingFallbacks += listOf("release")
}
```

特性：

- 啟用 R8 程式碼壓縮與資源縮減。
- 使用 Android Debug 金鑰簽署。
- 版本名稱加上 `-prerelease`。
- 不可上架 Google Play，也不適合作為長期正式版本。

R8 規則位於 `app/proguard-rules.pro`，目前保留 WebView JavaScript Bridge 的公開成員，避免方法被移除或重新命名。

## 7. 專案結構

```text
app/src/main/java/com/minireader/app/
├── MainActivity.kt              # 入口、顯示模式與根主題
├── MiniReaderApp.kt             # Application、AppContainer
├── data/
│   ├── db/                      # Room entities、DAO、資料庫
│   ├── epub/                    # EPUB 解析、ZIP、字數統計
│   ├── prefs/                   # DataStore 偏好設定
│   └── repository/              # BookRepository、BookImporter
└── ui/
    ├── icons/                   # 自訂圖示
    ├── navigation/              # NavHost
    ├── reader/                  # 閱讀器、WebView、注入樣式
    ├── settings/                # 閱讀設定
    ├── shelf/                   # 書架、標籤、詳細資訊
    ├── system/                  # 系統列外觀
    └── theme/                   # Material 主題
```

## 8. 測試

```bash
./gradlew :app:testDebugUnitTest
```

目前測試涵蓋：

- EPUB 解析與目錄。
- 字數統計。
- HTML 注入與不安全內容移除。
- 主題對比度。
- 顯示模式解析與主題分流。

新增邏輯時，優先為純 Kotlin 邏輯補上單元測試。涉及 WebView 或 Room 的行為，建議使用 Android  instrumentation test 或手動測試清單。

## 9. 手動測試清單

### 書架

- 匯入單本／多本 EPUB。
- 匯入重複檔案，確認顯示重複。
- 搜尋書名、作者、標籤。
- 切換排序。
- 建立、編輯、刪除標籤。
- 長按書籍：詳細資訊、重新命名、設定標籤、刪除。
- 確認封面、進度條、未讀／已讀完徽章、最近閱讀時間。

### 閱讀器

- 開啟書籍並還原進度。
- 目錄跳轉。
- 加入書籤、點擊書籤、刪除書籤。
- 章節底部上一章／下一章。
- 左滑上一章、右滑下一章（需超過半螢幕）。
- 點擊內容顯示／隱藏工具列。
- 切換顯示模式與護眼模式，確認閱讀頁與系統列同步。

### 設定

- 系統／淺色／深色。
- 淺色與深色護眼模式各自記住選擇。
- 字體、字級、行距、字距、段落間距、邊距、對齊、首行縮排。
- 保持螢幕亮起。
- 確認已無亮度、色溫選項。

## 10. 發行流程

1. 更新 `app/build.gradle.kts` 的 `versionCode` 與 `versionName`。
2. 更新 `CHANGELOG.md`。
3. 執行測試：

   ```powershell
   .\gradlew.bat :app:testDebugUnitTest
   ```

4. 建置 Pre-release：

   ```powershell
   .\gradlew.bat :app:assemblePrerelease
   ```

5. 確認 APK：

   ```powershell
   & "$env:LOCALAPPDATA\Android\Sdk\build-tools\36.0.0\aapt2.exe" dump badging app\build\outputs\apk\prerelease\app-prerelease.apk
   & "$env:LOCALAPPDATA\Android\Sdk\build-tools\36.0.0\apksigner.bat" verify --print-certs app\build\outputs\apk\prerelease\app-prerelease.apk
   ```

6. 建立 Git commit 與 tag：

   ```bash
   git add .
   git commit -m "Release v1.0.0-prerelease"
   git tag v1.0.0-prerelease
   git push origin main
   git push origin v1.0.0-prerelease
   ```

7. 建立 GitHub Pre-release：

   ```bash
   gh release create v1.0.0-prerelease \
     app/build/outputs/apk/prerelease/app-prerelease.apk \
     --title "v1.0.0-prerelease" \
     --notes "此版本為 Pre-release 測試版本，非正式上線版本。" \
     --prerelease
   ```

## 11. 常見問題

### 建置時找不到 SDK

確認 `local.properties` 的 `sdk.dir` 正確，且 Android SDK Platform 35 已安裝。

### R8 後 JavaScript Bridge 失效

確認 `app/proguard-rules.pro` 保留 `ReaderJsBridge` 的成員，或改用：

```proguard
-keepclassmembers class * {
    @android.webkit.JavascriptInterface <methods>;
}
```

### 安裝時簽章衝突

Debug、Pre-release 與其他版本可能使用不同簽章。先解除安裝舊版，或統一簽章設定。

### 版本名稱不是 1.0.0-prerelease

確認使用 `assemblePrerelease`，而不是 `assembleDebug` 或 `assembleRelease`。Pre-release 的版本後綴由 build type 的 `versionNameSuffix` 產生。
